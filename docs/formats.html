About the binary export

File > Export > Binary writes big-endian numbers, variable-length integers, a shared string table and flag bytes. The sample rig is 7.8 KB as JSON and 2.0 KB as binary.

Experimental: written from the public format description and checked only by round trip through Osteon2D's own reader (every attachment type, weighted meshes, deform, all timeline kinds). It has not been verified against Esoteric's loaders. Slider constraints and 4.3 transform property links are left out with a warning. Prefer JSON for production.
