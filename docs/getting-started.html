Getting started

Install

Download from the Releases page: OsteonSetup.exe (per-user installer, no admin rights) or the portable zip. Requires Windows 10/11 x64 and a Direct3D 11 GPU (falls back to WARP software rendering).

Your first animation

  1. File > Import PSD... for layered art, Import Multiple Images... for loose PNGs, or Import Data... for an existing Spine JSON.
  2. Press N (Create) and drag in the viewport to make bones. A bone made while another is selected becomes its child.
  3. Select an image, press P, click a bone to parent it. Rotate C, translate V, scale X, shear Z.
  4. Ctrl+Tab switches to Animate mode. With Auto Key on, every change is keyed at the current frame. Scrub the ruler, press D to play.
  5. Ease keys in the Graph view (Linear, Stepped, Bezier presets).
  6. Ctrl+S saves an .ost project, Ctrl+E exports, Ctrl+P packs a texture atlas.

All hotkeys: Help > Hotkeys (F1).

Export for a game

  1. File > Export > JSON (or Binary, experimental).
  2. Tools > Texture Packer writes name.atlas plus page PNGs.
  3. Put both in your engine project and follow the runtime guide.

Build from source

Visual Studio 2022 with "Desktop development with C++".

build.bat          :: Release build -> build\Osteon.exe
build.bat test     :: build, then run the test suites
