Languages

Settings > General > Language switches the editor between English, Español, Français, Deutsch, Português (BR), हिन्दी, 简体中文 and 日本語.

  • Translated: menus, panels, toolbar and timeline labels, the hotkey table, the Settings dialog.
  • Still English: status and error messages and long help tooltips. Anything untranslated falls back to English.
  • Hindi is drawn without text shaping (an ImGui limitation). Hindi, Chinese and Japanese use Windows system fonts.
  • Translations were written without native-speaker review. Corrections are welcome: edit the tables in src/editor/tr_*.inc and open a pull request.

Documentation

The README is available in Hindi, Spanish, Chinese, Japanese and Brazilian Portuguese.
