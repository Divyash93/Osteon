## Osteon क्या है?

Osteon एक नेटिव डेस्कटॉप एडिटर है जिसमें आप अपनी आर्टवर्क पर बोन (हड्डियाँ) बनाते हैं, उनसे इमेज या मेश जोड़ते हैं, और समय के साथ पोज़ की कीफ़्रेम बनाकर 2D किरदारों को एनिमेट करते हैं। यह एक छोटी नेटिव एक्ज़ीक्यूटेबल (C++20, Direct3D 11, Dear ImGui) है; ब्राउज़र, अलग रनटाइम या अकाउंट की ज़रूरत नहीं।

> **Spine से प्रेरित, उसकी नकल नहीं।** Osteon, Esoteric Software के [Spine](https://esotericsoftware.com) से प्रेरित है, लेकिन इसका इरादा पूरे सॉफ़्टवेयर की प्रतिकृति बनाना **नहीं** है। यह अपने कोड और अपनी दिशा वाला स्वतंत्र प्रोजेक्ट है। जहाँ उचित हो, यह सार्वजनिक रूप से प्रलेखित Spine JSON फ़ॉर्मेट पढ़ता और लिखता है।

## डाउनलोड

नवीनतम इंस्टॉलर **[Releases पेज](https://github.com/Divyash93/Osteon/releases/latest)** से लें: `OsteonSetup.exe` (इंस्टॉलर, एडमिन अधिकार नहीं चाहिए) या `Osteon-0.1.0-win64.zip` (पोर्टेबल)। ज़रूरत: Windows 10/11 (x64) और Direct3D 11 GPU। यह अभी शुरुआती (early alpha) संस्करण 0.1.0 है।

## मुख्य सुविधाएँ

- **रिगिंग:** बोन, स्लॉट, स्किन, ड्रॉ ऑर्डर, Pose/Create टूल, Rotate/Translate/Scale/Shear गिज़्मो।
- **आर्ट:** रीजन, मेश, लिंक्ड मेश, बाउंडिंग बॉक्स, क्लिपिंग, पाथ; **PSD**, एक इमेज या कई इमेज इम्पोर्ट।
- **वेट्स:** Bind, Auto, Smooth, Prune, ब्रश और डायरेक्ट पेंटिंग।
- **कंस्ट्रेंट:** IK, ट्रांसफ़ॉर्म, पाथ और फ़िज़िक्स।
- **एनिमेशन:** डोपशीट, ग्राफ़ एडिटर, ऑटो की, प्रीव्यू।
- **आउटपुट:** `.ost`, Spine JSON, PNG सीक्वेंस, GIF, वीडियो, टेक्स्चर एटलस।
- ऑटो-सेव और क्रैश रिकवरी, हर बदलाव पर Undo/Redo।

## रनटाइम (जल्द आ रहे हैं)

गेम में एनिमेशन चलाने के लिए आधिकारिक रनटाइम **जल्द आ रहे हैं**: Unity, Godot, Unreal Engine, वेब (PixiJS, Phaser, WebGL) और C/C++ इंजन। इनका काम अभी शुरू नहीं हुआ है।
